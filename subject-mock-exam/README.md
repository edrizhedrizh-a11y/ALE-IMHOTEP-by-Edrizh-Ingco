# ALE IMHOTEP Subject Mock Exam

Folder: /subject-mock-exam/

Features:
- Choose subject
- Choose question range
- Choose number of items
- Sequential or random mode
- Timer modes
- iPad/phone friendly layout
- Mark questions: Sure / Not Sure / Guess / No Idea
- Resume autosaved attempt
- Review missed
- Writing/marking canvas mode
- Skips image-identification cards with missing visuals

This mock exam loads cards from subject folders such as:
- /architectural-design/cards.json
- /theory/cards.json
- /planning/cards.json
- /professional-practice/cards.json
- /building-laws/cards.json
